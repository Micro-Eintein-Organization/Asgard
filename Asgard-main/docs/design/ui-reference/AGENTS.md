# Frontend reference boundary

This subtree is historical frontend reference material. Read [README.md](README.md) before using it.

- Current project instructions, requirements, recorded decisions and approved UI specifications govern implementation. This snapshot does not override them.
- Use the source to understand layouts, styling and possible reusable markup. Some designs and interactions are inaccurate or incomplete; check the current page guide and Figma references first.
- Treat catalog/questionnaire values and types as prototype fixtures, not approved product or data contracts.
- Do not implement a backend to satisfy the snapshot's `/api/state` calls. No backend is included or approved here.
- Do not import the whole prototype into the application. Adapt presentation only within a separately authorized implementation task and its reviewed boundaries.
- Preserve this snapshot unless explicitly asked to update it. Make implementation changes in the authorized application location, not in these reference files.
- Do not claim a runtime, design-fidelity or accessibility pass from source inspection or historical build records.

These instructions scope reference use; they do not start an implementation task.
