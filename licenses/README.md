For the Philippine sources, determine ownership and applicability document by document. Section 176 of the Philippine Intellectual Property Code addresses government works and requires prior agency approval for exploitation for profit where applicable. Record that determination and any permission in the source inventory before external publication. [Republic Act No. 8293, section 176](https://elibrary.judiciary.gov.ph/thebookshelf/showdocs/2/4371)
